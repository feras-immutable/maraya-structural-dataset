# Versioning Policy

v1.0.0 — First public release (current)
v1.x.0 — Corrections: typo fixes, note clarifications, confidence adjustments. No structural changes. Safe to update without breaking code.
v2.0.0 — Structural changes: new fields, schema changes, pivot revisions. May require code updates. Will be announced with migration guide.

Follows semantic versioning. Dataset version tracked in `schema_version` field inside the JSON.
